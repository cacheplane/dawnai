ServiceAccount / namespace wiring:

This app's Pod runs under ServiceAccount "{{ include "dawn-app.serviceAccountName" . }}"
in the dawn-app management namespace "{{ .Release.Namespace }}". Keep this namespace, the
app credentials, and both charts' Helm release Secrets separate from the
sandbox namespace "{{ .Values.sandboxNamespace }}". For the in-cluster
kubernetesSandbox provider (baked into your image's dawn.config.ts) to work,
that ServiceAccount must be bound to the dawn-sandbox-infra chart's orchestrator
Role.

By default, sandbox resources live in dawn-sandboxes while the application,
credentials, and Helm releases live in the separate dawn-app management
namespace.

{{- if .Values.serviceAccount.create }}

serviceAccount.create=true (default) — this chart created the ServiceAccount
above in THIS namespace ("{{ .Release.Namespace }}"). An empty
serviceAccount.name resolves to the release-scoped chart fullname.
{{- else }}

serviceAccount.create=false — this chart is using the operator-provided
ServiceAccount named "{{ include "dawn-app.serviceAccountName" . }}" in the
management namespace. Confirm it exists before sending traffic.
{{- end }}

Before sending sandbox traffic, bind that ServiceAccount to the sandbox-infra
orchestrator Role without overwriting existing cross-namespace subjects.

First capture the installed infrastructure chart version and export the
release's effective values:

  INFRA_CHART_VERSION="$(helm get metadata dawn-sandbox-infra --namespace {{ .Release.Namespace }} | awk '$1 == "VERSION:" { print $2 }')"
  test -n "$INFRA_CHART_VERSION"
  helm get values dawn-sandbox-infra --all --output yaml \
    --namespace {{ .Release.Namespace }} \
    > dawn-sandbox-infra-rbac-values.yaml

Edit dawn-sandbox-infra-rbac-values.yaml so `orchestrator.subjects` contains the
complete intended subject list: preserve every existing item and append the
application ServiceAccount as a cross-namespace subject:

  - kind: ServiceAccount
    name: {{ include "dawn-app.serviceAccountName" . }}
    namespace: {{ .Release.Namespace }}

Inspect the complete file, then apply it. Helm replaces arrays, so never write
a guessed numeric subject index:

  helm upgrade dawn-sandbox-infra \
    oci://ghcr.io/cacheplane/charts/dawn-sandbox-infra \
    --version "$INFRA_CHART_VERSION" \
    --namespace {{ .Release.Namespace }} \
    --values dawn-sandbox-infra-rbac-values.yaml

Make sure your app's `dawn.config.ts` points the kubernetesSandbox provider at
the same namespace as the dawn-sandbox-infra chart:

  sandbox: {
    provider: kubernetesSandbox({ namespace: "{{ .Values.sandboxNamespace }}" })
  }

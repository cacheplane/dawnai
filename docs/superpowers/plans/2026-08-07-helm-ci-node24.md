# Helm CI Node 24 Refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Dawn's active Kind-based CI jobs onto a Node 24 action runtime and a Kubernetes 1.35-compatible Calico release without changing Helm chart behavior.

**Architecture:** A focused sandbox-package policy test reads the active CI workflow and locks both dependency versions and their expected reference counts. The workflow then upgrades its three Kind action references and two Calico manifest references; existing chart and full-cluster lanes provide behavioral verification.

**Tech Stack:** GitHub Actions YAML, Vitest, TypeScript, Helm, kubeconform, Kind, Kubernetes, Calico

- [ ] **Step 1: Write the failing workflow policy test**

Create `packages/sandbox/test/ci-workflow-pins.test.ts`:

```ts
import { readFileSync } from "node:fs"
import { describe, expect, test } from "vitest"

const ciWorkflow = readFileSync(
  new URL("../../../.github/workflows/ci.yml", import.meta.url),
  "utf8",
)

describe("Kubernetes CI dependency pins", () => {
  test("uses the approved Node 24 Kind action in every active lane", () => {
    const commits = [
      ...ciWorkflow.matchAll(
        /^\s*uses:\s+helm\/kind-action@([^\s#]+)(?:\s+#.*)?$/gm,
      ),
    ].map(([, commit]) => commit)

    expect(commits).toEqual(
      Array.from(
        { length: 3 },
        () => "ef37e7f390d99f746eb8b610417061a60e82a6cc",
      ),
    )
  })

  test("uses the Kubernetes 1.35-compatible Calico release in every active lane", () => {
    const versions = [
      ...ciWorkflow.matchAll(
        /^\s*kubectl apply -f https:\/\/raw\.githubusercontent\.com\/projectcalico\/calico\/(v[^/]+)\/manifests\/calico\.yaml\s*$/gm,
      ),
    ].map(([, version]) => version)

    expect(versions).toEqual(["v3.32.1", "v3.32.1"])
  })
})
```

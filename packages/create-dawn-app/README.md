# create-dawn-ai-app

Scaffold a Dawn application with the supported starter templates and canonical route layout.

```bash
npm create dawn-ai-app@latest my-app
```

`bin.create-dawn-ai-app` is a node-only, supported tooling executable. Node.js 24 or later is required.

See its [API catalog entry](https://dawnai.org/docs/api#create-dawn-ai-app) and [Getting Started](https://dawnai.org/docs/getting-started).

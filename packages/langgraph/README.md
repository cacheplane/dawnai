# @dawn-ai/langgraph

LangGraph runtime adapters and route module contracts (`graphAdapter`, `workflowAdapter`, `defineEntry`) used by the Dawn CLI.

```ts
import { defineEntry, graphAdapter, normalizeRouteModule } from "@dawn-ai/langgraph"
```

- `@dawn-ai/langgraph` — edge-safe, supported integration surface.
- `@dawn-ai/langgraph/define-entry` — edge-safe, supported integration surface.
- `@dawn-ai/langgraph/route-module` — edge-safe, supported integration surface.

See the [LangGraph API reference](https://dawnai.org/docs/api/langgraph) for exact exports, route-module validation, adapter behavior, and compatibility boundaries. For application authoring, start with [Routes](https://dawnai.org/docs/routes).

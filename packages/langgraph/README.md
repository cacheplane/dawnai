# @dawn-ai/langgraph

LangGraph runtime adapters and route-module contracts used by Dawn.

```bash
pnpm add @dawn-ai/langgraph
```

```ts
import { defineEntry, graphAdapter } from "@dawn-ai/langgraph"
```

- `@dawn-ai/langgraph` is an edge-safe, supported integration surface.
- `@dawn-ai/langgraph/define-entry` is an edge-safe, supported integration surface.
- `@dawn-ai/langgraph/route-module` is an edge-safe, supported integration surface.

See the [API reference](https://dawnai.org/docs/api/langgraph) and [Routes guide](https://dawnai.org/docs/routes).

# @dawn-ai/vite-plugin

Internal Vite integration for Dawn's type-generation pipeline.

```ts
import dawn from "@dawn-ai/vite-plugin"
```

`@dawn-ai/vite-plugin` is a node-only, internal runtime surface for Dawn tooling.

See the [API catalog entry](https://dawnai.org/docs/api#dawn-aivite-plugin) and [Routes guide](https://dawnai.org/docs/routes).

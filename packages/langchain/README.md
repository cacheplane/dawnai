# @dawn-ai/langchain

LangChain adapters for Dawn agents, chains, tools, streaming, and retry.

```bash
pnpm add @dawn-ai/langchain
```

```ts
import { chainAdapter, openaiEmbedder } from "@dawn-ai/langchain"
```

`@dawn-ai/langchain` is an edge-safe, supported integration surface. Its `package.json` subpath is metadata for tooling, not runtime code.

See the [API reference](https://dawnai.org/docs/api/langchain) and [Agents guide](https://dawnai.org/docs/agents).

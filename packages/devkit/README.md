# @dawn-ai/devkit

Internal scaffold templates and generated-app test utilities shared by Dawn tooling.

```ts
import { resolveTemplateDir } from "@dawn-ai/devkit"
```

`@dawn-ai/devkit` is a node-only, internal runtime surface for Dawn's own scaffolding.

See the [API catalog entry](https://dawnai.org/docs/api#dawn-aidevkit) and [Getting Started](https://dawnai.org/docs/getting-started).
